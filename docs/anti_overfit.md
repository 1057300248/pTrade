# 高维因子挖掘防过拟合协议

本协议为「高维因子挖掘」工作的强制性规范。所有实现者（研究端与实盘端）**必须**遵守以下规则，任何违反均视为结果无效。

## 1. 扩展式滚动前推验证（Expanding Walk-Forward）

- 一律采用扩展窗口的 walk-forward 流程：训练窗口只向前扩展，验证窗口始终位于训练窗口之后。
- **严禁在全样本上调参**。任何在全样本上搜索出来的超参数、因子权重或阈值一律作废。

## 2. 参数冻结与样本外报告

- 参数在 **2018–2021** 区间内确定并冻结，之后不得再改动。
- **2022–2026 的样本外（OOS）表现是唯一有效的评价数字**。样本内指标只能用于诊断，不得作为结论汇报。

## 3. 压力测试不是训练目标

- **2024-02**（微盘股流动性危机）与 **2026-07**（最近一次极端行情）是压力测试场景，仅用于检验已冻结策略的生存能力。
- 严禁把这两个时段纳入训练集，严禁针对这两个时段反向调整任何参数或规则。

## 4. 实盘因子数量上限

- 经 IC 过滤后，进入实盘的因子数量 **不得超过 4 个**。
- 高维挖掘只发生在研究端；实盘端只接收少量、稳定、可解释的因子。

## 5. PTrade 实盘文件禁用 sklearn

- PTrade 实盘策略文件中 **不得出现任何 `sklearn` 依赖**（包括间接 import）。
- 模型训练、特征筛选等重活全部留在研究端，实盘端只做简单的线性打分或规则判断。

## 6. 多重检验校正（Deflated Sharpe）

- 报告 Sharpe 时必须同时报告 **Deflated Sharpe Ratio**，并如实申报尝试过的策略/因子组合总数。
- 挖了 100 个因子只报最好的 1 个而不做多重检验校正，属于数据窥探，结果作废。

## 7. 「看过 2026-07 才成立」的方案直接拒绝

- 如果某个方案（因子、参数、规则）只有在观察了 2026-07 行情之后才表现合格，**直接拒绝**，不给二次机会。
- 判据：把该方案放回 2026-07 之前的冻结流程中，若无法独立成立，即为事后拟合。

## 8. 图表不构成证据

- Cloud Desktop 可以绘制 IC 热力图等可视化产物，用于辅助理解。
- 但**图表本身不是证据**：任何结论必须附带可复现的数字（OOS 收益、IC 序列统计、Deflated Sharpe 等）与生成代码，仅凭图好看不得通过评审。
