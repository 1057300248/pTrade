# RMDC：残差动量去拥挤 ETF 轮动（国金 PTrade 主策略）

实盘文件：[`ptrade_rmdc_etf.py`](../ptrade_rmdc_etf.py)。整文件粘贴进国金 PTrade，业务类型 ETF，建议分钟周期（保住 14:45/14:50/14:54 时点）。国金 PTrade 已是 **Python 3.11**；文件仍不写 f-string，以兼容 SimTradeLab 前置过滤和旧版粘贴。2026 年市场与平台约束见 [`2026_a_share_quant_and_ptrade.md`](2026_a_share_quant_and_ptrade.md)，本文不重复。

## 与旧 `regime_etf_rotation.py` 的差别

RMDC 是从零重写，不是旧状态机轮动的调参版：

| | 旧 regime_etf_rotation | RMDC |
| --- | --- | --- |
| 状态判定 | 510300 vs MA60 单指标 | 成长袖仓广度 + 中位波动，四状态 |
| 打分 | 绝对动量 × R² × 效率 | 剥离市场 beta 与规模因子后的残差动量 |
| 拥挤 | 无 | 华泰式 0–4 打分，≥3 否决新开仓 |
| 相关性 | 无（半导体/创业板/科创50 可同持） | 60 日相关 >0.65 去重，防止一笔交易三个名字 |
| 权重 | 等权 2 只 | 波动倒数 + 12% 组合波动目标 |
| 调仓 | 日频 14:50 | 周频调仓 + 日频崩盘/止损 overlay |
| 跨境 ETF | 可进成长池 | 只进防御袖仓，513 溢价 ≥3%（对 IOPV）拒买 |

## 公式

1. **残差动量**：ETF 日对数收益对 `[常数, r_300, r_500 − r_300]` 做 120 日 OLS（跳过最近 5 日），分数 = 最近 60 日残差之和 / 残差标准差。排序分 = 残差动量 × 趋势质量（收盘 / 120 日最高价）。
2. **拥挤 0–4 分**：① 20 日均量 / 60 日中位量 >2；② 收盘 / MA60 − 1 >15%；③ 20 日价量相关 <0.10（放量滞涨）；④ 20 日均振幅 >4%。每项 1 分，**≥3 分不可新开仓**。
3. **状态机**：广度 = 成长袖仓 20 日收益为正的占比；中位波动 = 成长袖仓 20 日年化波动中位数。广度≥60% 且波动≤30% → offense；广度<40% 或波动>40% → defense；其余 balanced；510300 单日 −6% 或 3 日 −8% → lockdown 至少 5 日。袖仓权重（成长/防御/现金）：offense 70/25/5，balanced 40/45/15，defense 0/65/35，lockdown 0/30/70。
4. **入选门槛**：拥挤 <3；63 日收益 >0 且不低于 511010 同期；成长袖仓另需趋势质量 ≥0.90。
5. **相关过滤**：按分数从高到低，与已选 60 日相关 >0.65 者剔除；成长前 5 名平均两两相关 >0.75 视为集体拥挤 → 成长仓减半、最多持 1 只。
6. **权重**：袖仓内按 1/vol20 加权（单票 ≤40%），整体缩放到 12% 年化波动目标；防御袖仓有成长持仓时不低于约 25%；换仓滞后——新票分数须 >旧票 × 1.20 才替换。
7. **日频 overlay**：成长持仓收盘价从高水位回撤 ≥20%，或单日/3 日 −8%，或 510300 触发崩盘 → 清成长，留最强防御 60%，锁定 5 日。

## 验证流程

1. 本地纯函数单测：`python -m pytest tests -q`。
2. 免费日 K（新浪 / 腾讯 / baostock / akshare / 同花顺免费 / free-stockdb）+ 研究回测：`research/fetch_free_etf_bars.py` → `research/backtest_rmdc_etf.py`。实盘只用 PTrade 数据，见 `research/data_sources.md`。
3. **SimTradeLab 只是第一道过滤**（日线）：`research/run_simtradelab_rmdc.py`，`broker_profile="auto"`——SimTradeLab 没有国金口径，**不要填 `guosheng`**（那是国盛，会误开 Python 3.5 检查）。它只能验证生命周期、T+1、佣金和语法；14:50/14:54 会被日线压成 15:00，废单、部分成交、`get_etf_info` 溢价都测不到。**不要为了回测去开 QMT**：API 不同，策略贴不过去。
4. 最终以国金 PTrade 分钟回测 + 仿真为准，佣金按真实费率、滑点不设 0。

## 压力窗口（回测必须单独看）

- **2024-02 微盘流动性危机**：确认收益不靠小票——池内最小宽基是 512100（中证1000），且 defense/lockdown 应已把仓位切向防御。
- **2026-07 动量/拥挤共振**：拥挤否决和相关过滤就是为这种窗口设计的，单独核对该月回撤与换仓记录。

`research/backtest_rmdc_etf.py` 会自动输出这两个窗口的收益与回撤。本地研究数字不能外推为实盘预期。
