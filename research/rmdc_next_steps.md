# RMDC 下一步:允许什么、禁止什么(本波次范围界定)

> 依据:`research/rmdc_return_drag.md`(§3、§5、§6、§10)。
> 本文只界定范围,不改代码。实盘 `ptrade_rmdc_etf.py` 本波次**零改动**。

## 1. 允许 vs 不允许:一条分界线

分界线只有一条:**让回测对齐实盘既有行为 = bug 修复,允许;
让实盘(或回测)采纳全样本消融调出来的参数 = 样本内调参,不允许。**

| 事项 | 性质 | 本波次 |
|---|---|---|
| 债券门槛只作用于进攻腿(对齐实盘 `_eligible()`) | bug 修复 | **已落地**(提交 `70dcdd9`) |
| 回测移植 `apply_hysteresis`(对齐实盘 1.20 倍挑战者门槛) | bug 修复/保真对齐 | **允许,可选**(见 §3) |
| 组合 E 全套(锁仓 5→0、ON=(0.85,0.15,0.00)、防守下限 0.15、换手 band) | 全样本调参 | **不允许** |
| 组合 E 的 8.23% CAGR 作为决策依据 | 样本内数字 | **不允许**——它不是走前验证结果(§10) |

理由重申(来自 §10):组合 E 的 8.23% 是 2018-2026 同一段样本上逐条消融再叠加的结果,
本质是样本内调参;而 hysteresis 移植与债券门槛修复一样,只是让
`research/backtest_rmdc_etf.py` 复现 `ptrade_rmdc_etf.py` **本来就在跑**的逻辑,
不引入任何实盘没有的自由度。

## 2. 下一步方向:不再拧 TQ / 拥挤度 / 崩盘 overlay

这三个旋钮在消融中已经证明是护城河或局部最优,**本波次及后续均不再重调**:

- **TQ >= 0.90**:0.80 与 0.95 双向都显著变差(-1.25pp / -1.49pp),0.90 已是局部最优。
- **拥挤度 >= 3 否决**:去掉少赚 0.94pp,是保护性规则。
- **崩盘 overlay**:去掉后 2026-07 回撤从 -1.44% 爆到 -8.48%,它是该窗口的全部答案。

排序不变(§10):① 修复类对齐(债券门槛已完成,hysteresis 见下);② 实测 §9 的 4 资产
ADM 假设;③ 只有 ADM 也失败,才回头对 RMDC 的锁仓/sleeve 类旋钮做**走前验证**。

## 3. 可选研究任务(仅回测):移植 `apply_hysteresis`,度量换手

**目的**:回测的 `weekly_target()` 目前每周从零重排(无状态、无在任者保护),
而实盘在 `_weekly_target` 里跑 `apply_hysteresis(held_keep, proposed, scores, g.hysteresis=1.20)`
——挑战者分数必须超过在任者 1.20 倍才换名。§3-#2 已量化:这个偏差让回测多付了
接近零成本上界 ~2pp/年的换手成本(8bp→0 时 CAGR 5.44%→7.93%)。移植后才能回答:
实盘真实的换手/成本拖累到底是多少,以及"选股粘性还能收回多少"这条路值不值得走。

**任务规格**(全部只动 `research/backtest_rmdc_etf.py`,不动实盘文件):

1. 把实盘 `apply_hysteresis()`(1.20 gap、在任者优先、按 proposed 长度截断)原样复制进回测;
   `weekly_target()` 需要接入上周持仓名单(现为无状态函数,主循环里已有 `holdings` 可传)。
   对齐点:实盘是先 `build_targets` 出 raw_weights → 取 `w >= min_weight` 的 proposed →
   `held_keep = 当前持仓 ∩ raw_weights` → hysteresis → 只保留幸存名单的权重。
2. 产出**换手度量报告**(前/后对照):成交次数(基线 459)、平均每次换手占 NAV 比例
   (基线 ~60%)、年化成本拖累(基线 ~2.5%/年)、CAGR/MDD/Sharpe、两个压力窗口
   (2024-02、2026-07)回撤。
3. **解读纪律**:移植后 CAGR 的变化读作"回测更接近实盘",**不是**调参收益;
   两个压力窗口回撤若明显变差(> 组合 E 参照:2024-02 dd -0.40% / 2026-07 dd -1.65%),
   说明实盘的 hysteresis 本身有隐患,应上报而非绕过。
4. 顺带记录但**不在本波次处理**的另两处已知偏差(§6):回测排名用 `score×TQ` 而实盘用
   裸 score;回测无 QDII 溢价否决/涨跌停否决。它们是下一轮对齐候选。

**明确不做**:不改 `ptrade_rmdc_etf.py` 的任何旋钮(`g.hysteresis`、`g.lockdown_days`、
`SLEEVE_WEIGHTS`、防守下限、`g.trail_pct` 等本波次全部冻结);不把组合 E 的任何参数
写进任何会被实盘引用的代码路径。
