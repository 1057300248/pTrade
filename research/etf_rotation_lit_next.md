## RL / ML / 神经网络 / 树 / 机器训练

### 实盘：不要开

国金 PTrade 已禁 sklearn、禁第 5 因子、禁神经网络。这不是权衡，是硬墙。

### 研究：也不优先

| 反对理由 | 文献锚 |
| --- | --- |
| 有效样本是「独立宏观状态」约 5–7 个，不是 1950 根日 K | 8 年 × 4 只高相关 ETF |
| PPO 在 3 资产、已知最优的模拟里要 ~200 万步才收敛（约 8000 年日频） | arXiv:2307.07694 |
| Jiang 2017 EIIE 搬到股票后退化到等权；成交量选池含幸存者偏差 | arXiv:2409.08426 |
| FinRL 同配置 Sharpe 在 0.1–2.7 之间抖；官方 notebook 复现失败 | GitHub issues #190 / #1070 / #1303 |
| SAC 在 300+ 年样本外加 10bp 成本后净收益转负 | *Finance Research Letters* 2025 |
| 个人账户不影响价格时，逐期凸优化在数学上优于 RL（幻影利润概率 0.6–0.8） | arXiv:2509.12764 |
| A 股拥挤度 + XGBoost/LSTM 择时不敌纯做多 | 招商 2020 |
| Gu–Kelly–Xiu 的树/NN 优势来自每月数千只股票横截面，不是 4–17 只 ETF 时序 | NBER w25398 |
| 本账高维 43 + 进化 30：**批准入实盘因子 = 0** | `factor_mine_highdim.md` |
| 波动预测：门限 HAR 常胜过 XGB/DNN；更准的波动也解决不了 Cederburg 的结构断点 | FEDS 2025；JFE 2020 |
| LLM 改策略：幻觉修改、策略漂移、预训练读过未来 | EvoQuant 自己承认；arXiv:2605.16895 |

波动目标、hysteresis、tranche、月门、逆波动加权**不是 RL**。它们是确定性规则，numpy 可写，且已在本账或预登记表里。

可接受的「统计」用法：用累计 N=16 算一次 Deflated Sharpe / bootstrap，**不训练模型**。

## 下一步优化（按优先级）

只动执行、仓位估计量或已预登记 overlay。信号回看期、崩盘阈值、资产池、GEM 转正一律不动。

### P0 — 纸面 `W2-TRANCHE-N2`（N_add = 0）

Wave 2 已按 IS 冻结选出 N=2 并通过 OOS 关卡，**尚未上实盘**。英文执行文献（Newfound 时点运气、Almgren–Chriss、Gârleanu–Pedersen、Concretum 2025 GTAA 分批）**独立**支持「冻结目标后拆单」，但不证明 N=2 最优，也禁止用本账 OOS 再扫 N=3/4。

纸面要单独记：

- T+1：普通 A 股 ETF 当日新买不能当日卖；崩盘同日豁免对**新买腿不对称**
- 8bp 按成交额计，两批各 0.5G 总成本仍是 `8bp × G`，不要按日翻倍
- 2026-07-06 起沪市基金 15:05–15:30 盘后固定价通道，回测「收盘成交」与实盘首次可对齐
- 跨境 / 债券 / 黄金 ETF 是 T+0，股票 ETF 是 T+1，篮子要按品种拆

默认：**纸面 ≥4 周 + SimTradeLab + 国金分钟仿真**，人工再决定是否改 `ptrade_adm_etf.py`。零晋级仍合格。

### P2 — 制度友好、需改写后再立项（研究-only 或防守过滤）

**QDII 溢价**：核实 513100 **2024-11-25** 起停申购（至 2026-08 仍未恢复）。「2026-04 额度扩容」应写成：**2026-03-27 外汇局公布 +53 亿美元，4 月部分产品放开申购**。

- 溢价当收益来源：研究-only。常态化始于 2024-11，IS 内只有 2020-02 一轮，不能当 alpha 立项。
- 溢价当**新开仓过滤器**：可作先验防守（行业 5% 警戒 / 管理人分层；做市商在偏离 ≥10% 时豁免报价）。实现只能用 T-1 收盘 / 最新净值，禁止核心路径 `get_snapshot`。这是对 `iteration_direction.md` 方向 D 的改写，**改写完成前不得进 N 台账**。

**债券停车加现金资格**（Keller BAA / Allocate Smartly 2022）：美国证据强，中国 511010 在 2018–2025 每年净值为正（2022 仍 +2.08%），先验比美国弱。列为**未来单独 +1**，排在黄金袖仓之后，不本波开。

**同指数低溢价替代腿**（513100 / 159941 / 513300 等）：纯执行映射，信号不动。先做研究对照，再决定是否预登记。
